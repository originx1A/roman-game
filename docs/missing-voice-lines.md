# Unseen voice lines

The eight lines from the 2026-10-20 handoff (commit 47d479a) now have recordings. Each one plays through the shared voice channel as the Unseen, so Roman stops and does not start another line while it is speaking. One line plays at a time.

A computer is a fine pointer on a window at least 900px wide (`(pointer: fine)` and not `(pointer: coarse)`). Anything else, including a device we cannot read, keeps the phone line. The user agent is not used.
