# 9.33-c home controls

One control for each job. Screenshots in this folder are signed out, from Playwright, at 1280×800, 1440×900, 390×844, and 375×667.

| Control | Where | Job |
| --- | --- | --- |
| Leaderboard panel | Desktop home, right column | The board is on home. There is no extra button to reveal it. |
| See all | That panel | Opens the centred board: Everyone, Friends, Groups, and Week/Month on Groups. |
| 🏆 Leaderboard | Phone home | Opens the same board. |
| Close | Centred desktop board | Closes the board and returns to home. |
| ☁ Save my scores | Desktop home | Opens the sign-in sheet (email, 13+, Terms). Signed in, it shows the account sheet. |
| Sign in | Phone home | Same sheet, short label. |
| Sign in to get on the board | Leaderboard, guests only | Same sheet. The guest prompt on the board. Hidden once signed in. |
| Unseen card | Home | Opens the card: pieces, how they are earned, and OK. |
| The Unseen | Desktop home, beside your buddy | Shows his line at once. The line stays up even if the sound does not start. Hidden on phones, where he would cover the grid. |
| How to play | Home | The demo. The first ordinary Play still opens it once. |
| Play daily | Daily Challenge card | Starts today's daily. It does not open the demo. |
| Remix | Remix card | Opens the remix boards. |
| + Create a group | Groups tab, signed in, not in a group | Pick an adjective and a noun. |
| My group | Groups tab, signed in, already in a group | Opens your group. |
| Requests | Board header and Groups tab, signed in | Friend requests and join requests. |

Removed: **Mix it up**. It only opened How to play. Remix is the control that opens the remix boards.

Play, Rewards, Stable, Share, and Save in the nav are those screens. The leaderboard is on home, so you do not have to start a game to reach Everyone, Groups, Week/Month, or Requests.
